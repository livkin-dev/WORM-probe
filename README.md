# WORM Probe 🪱

Кроссплатформенный диагностический скрипт для аудита сетевой цензуры, мониторинга доступности API (LLM-модели, мессенджеры, экосистемы) и тестирования DNS-резолверов. 

Инструмент измеряет параметры маршрутизации и задержки, собирая структурированную телеметрию для аналитики блокировок в рамках проекта Monitor Runet.

## Возможности

* **Кроссплатформенность:** Нативные скрипты для macOS/Linux (`bash`) и Windows (`PowerShell`).
* **Динамическая конфигурация:** Списки целевых эндпоинтов и резолверов загружаются напрямую из `endpoints.txt` и `resolvers.txt` при каждом запуске.
* **Мульти-резолвинг:** Проверка доступности эндпоинтов через системный DNS, DoH (Cloudflare, Yandex) и классические UDP-резолверы.
* **Автоматическое определение гео/ISP:** Интеграция с `ipinfo.io` для привязки результатов к конкретному провайдеру и локации.
* **Совместимость с El Vigía:** Экспорт данных в гибридный CSV-формат (разделитель `;`, кавычки, тайминги до микросекунды), полностью совместимый с парсерами отчетов Ping-Admin.
* **Бессерверная отправка:** Прямая выгрузка собранных отчетов в Google Forms через `curl`.

## Управление конфигурацией

Скрипт автоматически скачивает актуальные списки из корня репозитория перед началом тестирования:
* `endpoints.txt` — список тестируемых URL (каждый с новой строки).
* `resolvers.txt` — список резолверов в формате `Имя|Тип|Адрес`.

Для изменения логики проверки достаточно отредактировать эти текстовые файлы в репозитории, править сами скрипты не нужно.

## Быстрый запуск

Скрипт не требует клонирования репозитория. Достаточно выполнить одну команду в терминале целевой машины.

### macOS / Linux (Bash)

```bash
curl -sL [https://raw.githubusercontent.com/livkin-dev/WORM-probe/main/worm.sh](https://raw.githubusercontent.com/livkin-dev/WORM-probe/main/worm.sh) | bash
```

### Windows (PowerShell)

```powershell
Invoke-RestMethod -Uri "[https://raw.githubusercontent.com/livkin-dev/WORM-probe/main/worm.ps1](https://raw.githubusercontent.com/livkin-dev/WORM-probe/main/worm.ps1)" | Invoke-Expression
```

## Формат экспорта данных

Генерируемый файл `worm_results_<timestamp>.csv` имеет следующую структуру:

| Колонка | Описание | Пример |
| :--- | :--- | :--- |
| `REGION` | Город и страна тестирования | `"Valencia ES"` |
| `ISP` | Провайдер (AS + Org) | `"AS200845 AVATEL TELECOM SA"` |
| `ENDPOINT` | Проверяемый хост | `"api.anthropic.com"` |
| `RESOLVER` | Используемый метод резолвинга | `"Cloudflare"` |
| `IP` | Разрешенный IP-адрес | `"160.79.104.10"` |
| `STATUS` | HTTP код ответа | `"404"` |
| `DNS, сек.` | Время разрешения имени | `"0.065000"` |
| `Ожидание ответа, сек.` | TTFB | `"0.196000"` |
| `Общее время, сек.` | Полное время запроса | `"0.196000"` |
| `BLOCKED` | Флаг ошибки / таймаута / блокировки | `"NO"` |
